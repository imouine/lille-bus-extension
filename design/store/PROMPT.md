# Prompt du fond de présentation

Le fond `assets/transit-background-v1.png` a été généré avec l’outil ImageGen intégré,
en mode création d’image, avec le prompt suivant :

> Use case: ads-marketing
> Asset type: reusable background for Chrome Web Store presentation screenshots, intended final ratio 16:10 (1280x800)
> Primary request: create a premium, modern abstract backdrop for a Lille public-transit browser extension, with generous negative space for later UI and typography overlays
> Scene/backdrop: deep midnight navy base, subtle cyan and electric-blue radial glows, elegant thin transit-route curves and small station dots flowing diagonally, very restrained lime and warm orange accent lights
> Style/medium: polished digital brand design, minimal, sophisticated, crisp, contemporary SaaS/product marketing
> Composition/framing: wide landscape, balanced but not symmetrical, quieter center-left and right zones for content placement, route lines around edges
> Lighting/mood: calm, reliable, fast, nighttime city mobility
> Color palette: #07131F, #0E2132, #38A9F5, #0876C1, tiny accents #45C695 and #FB923C
> Constraints: absolutely no text, no logos, no UI, no buses, no people, no buildings, no icons, no watermark; keep visual detail subtle so white text remains highly legible

Le texte et les interfaces ont ensuite été composés dans les SVG de `slides/` pour
conserver une typographie nette et une représentation fidèle du produit.
